# Security

Sillage is a demonstration application. It holds seeded fiction, no real client data and no payment details.

## Report a problem

Write to devtechedge@gmail.com with the affected route, a short reproduction and the impact. Do not open a public issue for a vulnerability that exposes another house's records.

## Supported version

The `main` branch and the current Vercel deployment.

## Scope

- Tenant isolation between houses
- Role checks on approval, trials, materials and production
- Session and password handling
- Atomic stock deduction and ledger integrity
- Cross-site scripting and request forgery

Reports about the fictional material costs or the accuracy of fragrance safety claims are out of scope. The interface states that costs, persistence and guardrails are house estimates, not regulatory advice.
